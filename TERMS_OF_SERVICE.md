## 2. Description of the Service

The Service provides an open standard Model Context Protocol (MCP) server enabling users and authorized AI assistant clients (such as Claude Desktop, Cursor, ChatGPT, and custom LLM sidecars) to:
- Connect social media platforms (**Twitter/X**, **Instagram/Meta**, **YouTube/Google**) via OAuth 2.0 / 2.1 PKCE.
- Publish and autonomously schedule text, image, and video content.
- Retrieve engagement analytics, follower insights, and algorithmic health diagnostics.
- Scout real-time public trending discussions (Reddit, Hacker News) and optimize SEO / CTR metadata using Google Gemini AI.
- Lock Brand Persona voice, tone, visual aesthetic, and forbidden buzzwords.
