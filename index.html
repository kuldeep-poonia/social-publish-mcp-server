Architecture & Resilience

Engineered Without Compromise.

Every layer—from kernel socket hooks to encrypted stream retries—is built for uninterrupted reliability.

Sync-First Resilient Dispatch

Zero-Latency First Attempt with Automated Redis Stream Fallback

Requests execute synchronously against upstream APIs for instant confirmation. If Twitter, YouTube, or Meta returns a 429 rate limit or 503 outage, the payload is automatically AES-encrypted and enqueued into a Redis 7 Stream for jittered exponential retries.

Security Protocol

Kernel Socket-Level SSRF Pinning

Prevents Time-of-Check to Time-of-Use (TOCTOU) DNS rebinding by inspecting resolved destination IPs directly via net.Dialer.Control at the OS kernel level before transmitting HTTP bytes.

169.254.169.254 (Cloud Metadata) 127.0.0.0/8 (Loopback) 10.0.0.0/8 (Private RFC1918)
Zero-Trust Storage

AES-256-GCM Token Vault

OAuth access and refresh tokens are encrypted at rest with distinct 96-bit random nonces. Master encryption keys are managed strictly out-of-band, never touching database backups.

Cipher = AES_GCM_256(Token, MasterKey, Nonce_96)

Model Context Protocol

The Complete Toolset.

Standard JSON-RPC 2.0 interface compatible with Claude Desktop, Cursor, and custom agent swarms.

publish_post.json 
// publish_post JSON-RPC 2.0 Protocol Schema
{
  "name": "publish_post",
  "description": "Publishes text updates, photo attachments, or video content to Twitter/X, YouTube, or Instagram.",
  "parameters": {
    "type": "object",
    "required": ["platform", "content"],
    "properties": {
      "platform": { "type": "string", "enum": ["twitter", "youtube", "instagram"] },
      "content": { "type": "string", "description": "Text caption or description" },
      "media_urls": { "type": "array", "items": { "type": "string" }, "description": "Public media URLs to attach" },
      "title": { "type": "string", "description": "Required for YouTube video uploads" },
      "visibility": { "type": "string", "enum": ["public", "unlisted", "private"], "default": "public" },
      "media_type": { "type": "string", "enum": ["IMAGE", "VIDEO", "REEL", "CAROUSEL"] }
    }
  }
}
