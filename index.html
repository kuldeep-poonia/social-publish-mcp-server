Zero-Trust Architecture

Built for High Security & Strict Isolation

LLMs never touch plaintext OAuth tokens. Every network socket, SQL query, and log line is hardened against adversarial attack vectors.

Kernel-Level Socket SSRF Guard

Uses net.Dialer.Control OS hooks to verify destination IPs at dial-time, completely neutralizing DNS rebinding and TOCTOU metadata exploits.

AES-256-GCM Token Vault

OAuth tokens encrypted at rest with unique 96-bit nonces. Master keys remain strictly out-of-band in secret managers, decoupled from database dumps.

Multi-Tenant Actor Isolation

Database queries evaluate cryptographic actor session contexts. Cross-user IDOR access attempts abort instantly with ErrUnauthorizedAccess.

Redis 7 Stream Retry Queue

Sync-first execution with automated exponential backoff retries on transient 429/503 errors and a 5-attempt poison message DLQ quarantine cap.

Dual-Layer Secret Scrubbing

Regex signature and key denylist filters automatically replace all bearer tokens, authorization headers, and secrets with [REDACTED] in telemetry.

TLS 1.2+ Forward-Secret AEAD

Network listeners strictly enforce TLS 1.2/1.3 with forward-secret AEAD cipher suites, actively rejecting obsolete SSLv3, TLS 1.0, and TLS 1.1 handshakes.

Model Context Protocol (MCP) Tool Suite

Seamless JSON-RPC 2.0 interface compatible with Claude Desktop, Cursor, Gemini CLI, and custom agents.

Tool Schema: publish_post 
// publish_post JSON-RPC 2.0 Schema
{
  "name": "publish_post",
  "description": "Publishes text updates, photo attachments, or video content to Twitter/X, YouTube, or Instagram.",
  "parameters": {
    "type": "object",
    "required": ["platform", "content"],
    "properties": {
      "platform": { "type": "string", "enum": ["twitter", "youtube", "instagram"] },
      "content": { "type": "string", "description": "Text caption or description" },
      "media_urls": { "type": "array", "items": { "type": "string" }, "description": "Public media URLs to attach" },
      "title": { "type": "string", "description": "Required for YouTube video uploads" },
      "visibility": { "type": "string", "enum": ["public", "unlisted", "private"], "default": "public" },
      "media_type": { "type": "string", "enum": ["IMAGE", "VIDEO", "REEL", "CAROUSEL"] }
    }
  }
}
